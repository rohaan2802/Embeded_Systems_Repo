Overview

Embedded Control of Robotics (CS-4095) at FAST-NUCES Islamabad, Fall 2025. The repository has all thirteen lecture sets, the course textbooks and outline, assignment statements with my solutions, my solved quizzes, study notes, Python scripts for PD and PID controller design, and our semester project on ROS 2.

Unit 1

Control basics

Robots and their components, open and closed loops, system properties and digital signals.

Unit 2

Modeling & analysis

Block diagrams, Laplace transform, transfer functions, poles and zeros, time and frequency response.

Unit 3

Control design

On-off, P, PI and PID control, tuning methods and Routh–Hurwitz stability.

Unit 4

Digital control

ADC and DAC, difference equations, z-transform, state space and filters.

Get the Files

Clone everything with Git, or run the PID design script.

Clone the repository

Command
git clone https://github.com/rohaan2802/Embeded_Systems_Repo.git

Run the PID design script

Command
pip install control matplotlib numpy pandas
cd Embeded_Systems_Repo/Notes
python pid_controldesign.py

The scripts were written in Google Colab. Remove the !pip install line before running them as plain Python, or open them in a notebook. The PDFs open directly on GitHub or in any PDF reader.
