## Course Overview

Embedded Control of Robotics (CS-4095) at FAST-NUCES Islamabad, Fall 2025. The repository has all thirteen lecture sets, the course textbooks and outline, assignment statements with my solutions, my solved quizzes, study notes, Python scripts for PD and PID controller design, and our semester project on ROS 2.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Control basics** | Robots and their components, open and closed loops, system properties and digital signals. |
| **Unit 2 – Modeling & analysis** | Block diagrams, Laplace transform, transfer functions, poles and zeros, time and frequency response. |
| **Unit 3 – Control design** | On-off, P, PI and PID control, tuning methods and Routh–Hurwitz stability. |
| **Unit 4 – Digital control** | ADC and DAC, difference equations, z-transform, state space and filters. |

## Running the Python Scripts

The `Notes` folder has two scripts from Lecture 7 that design P, PI, PD and PID controllers with the Cohen–Coon method and plot their step responses. They were written in Google Colab, so remove the `!pip install` line before running them as plain Python:

```bash
git clone https://github.com/rohaan2802/Embeded_Systems_Repo.git
cd Embeded_Systems_Repo/Notes
pip install control matplotlib numpy pandas
python pid_controldesign.py
```
